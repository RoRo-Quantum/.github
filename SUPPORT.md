# Support

Need help? Here are the right channels:

- 🐛 **Bug report / feature request** → open an **Issue** in the relevant repo.
- 💬 **General question / discussion** → the repo **Discussions** tab (if enabled).
- 🔐 **Security vulnerability** → use the private channel in [SECURITY.md](SECURITY.md) (do not open an issue).

> Before opening an issue, please search to see if it has already been reported.
