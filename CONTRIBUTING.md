# Contributing

Thanks for your interest in contributing to RoRo Quantum! 🎉
These are the default rules for all repositories across the organization.

## Before you start

- By contributing, you agree to our [Code of Conduct](CODE_OF_CONDUCT.md).
- Planning a large change? Open an **issue** first to discuss it.
- Small fixes (typos, docs) can go straight to a PR.

## Development workflow

1. **Fork** the repo (external contributors) or create a **branch** (team members).
2. Branch naming: `feature/...`, `fix/...`, `docs/...`, `chore/...`
3. Make your change and add **tests** where possible.
4. Use [Conventional Commits](https://www.conventionalcommits.org/) for commit messages:
   - `feat: a new feature`
   - `fix: a bug fix`
   - `docs: documentation only`
   - `refactor:`, `test:`, `chore:`
5. Open a **Pull Request** against `main`.

## Pull Request rules

- PR title should follow Conventional Commits.
- CI (if present) must be green.
- At least **1 approval** is required.
- Describe *what* and *why* in the description; the *how* lives in the code.
