# .github

Organization-wide community files and defaults for **RoRo Quantum**.
Files here are **automatically applied** to every repository in the org that
doesn't provide its own copy.

## Contents

| File / Folder | Purpose |
|---------------|---------|
| `profile/README.md` | The intro shown at the top of the org page |
| `CODE_OF_CONDUCT.md` | Community code of conduct (org-wide default) |
| `CONTRIBUTING.md` | Contribution guide (org-wide default) |
| `SECURITY.md` | Vulnerability disclosure policy (org-wide default) |
| `SUPPORT.md` | Where to get help |
| `.github/ISSUE_TEMPLATE/` | Default issue templates |
| `.github/PULL_REQUEST_TEMPLATE.md` | Default PR template |
| `docs/REPO_STANDARDS.md` | Standards to follow when creating a new repo |

> If a repo adds its own `CONTRIBUTING.md`, that one wins over the default here.

## Creating a new repo

Follow the checklist in [docs/REPO_STANDARDS.md](docs/REPO_STANDARDS.md).
